Sobre o LaborFuture

Objetivo

O LaborFuture é uma aplicação desenvolvida para a Global Solution da FIAP, com foco em analisar o futuro do trabalho até 2050, considerando o avanço da Inteligência Artificial, novas tecnologias, sustentabilidade e a valorização do trabalho braçal qualificado.

Tecnologias utilizadas

  • API RESTful com Spring Boot;
  • Banco de dados Oracle (FIAP) com Spring Data JPA;
  • Front-end com Thymeleaf;
  • Estilização com Bootstrap + CSS custom;
  • Validações com DTOs (records) e Bean Validation.

Funcionalidades

  • Cadastro e login de usuários;
  • Página interativa sobre o futuro do trabalho;
  • Exploração de profissões em destaque e detalhes específicos;
  • Mapa de habilidades essenciais;
  • Análise do impacto da IA e empregos resilientes;
  • Trilhas de requalificação para diferentes perfis;
  • Área administrativa simples para gestão de usuários (apenas admin).

Alinhamento com o tema

A aplicação mostra que a IA não extingue todo o trabalho, mas transforma funções, exige requalificação contínua e reforça a importância de quem constrói, mantém e opera o mundo físico. O LaborFuture orienta essa transição.
